# Les Questions de Lio

Les Questions de Lio est une application web simple permettant de générer aléatoirement des questions pour animer des discussions entre amis, en couple ou en famille.

## Fonctionnalités

* Questions aléatoires
* Filtrage par catégories
* Interface moderne et responsive
* Chargement des questions depuis un fichier JSON
* Hébergement statique vercel

## Catégories disponibles

* Chill et loisirs
* Ego et personnalité
* Profond et philosophique
* Romance et intimité
* Relations et groupe
* Enfance et nostalgie
* Notes et échelles

## Lancement local

1. Télécharger ou cloner le projet.
2. Ouvrir le dossier dans un navigateur ou lancer un serveur local.

Exemple avec Python :

```bash
python -m http.server 8000
```

Puis ouvrir :

```
http://localhost:8000
```

## Technologies utilisées

* HTML5
